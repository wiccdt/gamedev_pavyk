# CHANGELOG

Короткая история разработки игры «Паук».

## Практика / домашняя работа №1

**Что сделано:**

- Заменён стартовый квадрат на паука, который цепляется паутиной за точки и раскачивается.
- Добавлены автоматическое подтягивание к точке, остановка подтягивания пробелом и отпускание нити кликом в пустое место.
- Добавлены мухи и счёт съеденных мух; неподвижные мухи размещены в уровне и появляются выше по мере продвижения.
- Добавлены платформы, ходьба по ним и прыжок.
- Добавлены бесконечное продолжение уровня вверх и камера, следующая за пауком.
- Добавлены поднимающаяся вода, таймер, пауза и перезапуск после поражения.
- Добавлена вторая фаза с шипами и предупреждением о её начале. Параметры фазы вынесены в `src/game/phaseConfig.ts`; текущий порог — 3 мухи.
- Настроена публикация через GitHub Pages с GitHub Actions.
- README обновлён: добавлены описание игры, управление, запуск и публикация.

**Что пришлось упростить:**

- Вместо готовых иллюстраций используются простые геометрические фигуры Phaser.
- Физика раскачивания и столкновения реализованы в небольшой игровой сцене без отдельного физического движка.

**Что оказалось сложнее, чем ожидалось:**

- Настроить движение на паутине так, чтобы было понятно, когда паук подтягивается, раскачивается и отпускает нить.
- Поддерживать последовательность точек зацепа, платформ, мух и препятствий при бесконечной генерации уровня.
- Настроить публикацию GitHub Pages и включить источник GitHub Actions.

**Где использовался AI:**

- Для реализации и корректировки игровых механик в `GameScene.ts`.
- Для проверки TypeScript и production-сборки.
- Для подготовки README и этого журнала изменений.
