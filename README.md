# Паук

Небольшая браузерная игра на **TypeScript, Phaser и Vite**. Играй за паука, раскачивайся на паутине, собирай мух и поднимайся выше, пока снизу наступает вода.

**Играть:** [https://wiccdt.github.io/gamedev_pavyk/](https://wiccdt.github.io/gamedev_pavyk/)

> Ссылка обновляется после успешной публикации через GitHub Actions. Если игра не открывается или в ней старая версия, проверь последний запуск workflow на вкладке Actions репозитория.

## Как играть

- **Цель:** собирать мух и продержаться как можно дольше. Счёт показывает количество съеденных мух, таймер — время игры.
- **Опасности:** вода постепенно поднимается. После достижения порога мух начинается вторая фаза — появляются шипы. Столкновение с водой или шипом завершает игру.
- **Уровень:** мир продолжается вверх; новые точки для паутины, платформы и мухи появляются по мере продвижения.

### Управление

| Действие | Управление |
|---|---|
| Зацепиться за голубую точку и начать подтягиваться | Клик по точке |
| Остановить подтягивание и раскачиваться на текущей длине нити | **Пробел**, пока паук на нити |
| Отпустить нить | Клик в пустое место |
| Двигаться по платформе | **A/D** или **←/→** |
| Прыгнуть с платформы | **Пробел** |
| Пауза / продолжить | **Esc** или **P** |
| Начать заново после поражения | Кнопка **«Начать сначала»** |

Вторая фаза настраивается в [`src/game/phaseConfig.ts`](./src/game/phaseConfig.ts). Сейчас она начинается после сбора **3 мух**.

## Запуск локально

Нужен Node.js **20.19 или новее** (рекомендуется Node.js 22).

```bash
npm install
npm run dev
```

Открой адрес, который Vite выведет в терминале (обычно `http://localhost:5173/`).

Проверка типов и production-сборка:

```bash
npm run typecheck
npm run build
```

Готовая сборка появится в `dist/`. Для локального просмотра production-сборки выполни `npm run preview`.

## Публикация

В репозитории настроен workflow GitHub Actions: `.github/workflows/deploy.yml`. Он собирает и публикует игру при push в ветку `main` или `master`.

Для публикации в собственном репозитории:

1. В настройках репозитория открой **Settings → Pages**.
2. В **Build and deployment → Source** выбери **GitHub Actions**.
3. Отправь изменения в `main` или `master`.
4. На вкладке **Actions** дождись успешного запуска **Deploy to GitHub Pages**.

## Технологии и структура

- **Phaser 4** — сцена, игровая графика и ввод.
- **TypeScript** — игровая логика и типы.
- **Vite** — локальный сервер и production-сборка.
- [`src/game/GameScene.ts`](./src/game/GameScene.ts) — механики и игровой цикл.
- [`src/game/phaseConfig.ts`](./src/game/phaseConfig.ts) — параметры второй фазы с шипами.
- [`src/game/config.ts`](./src/game/config.ts) — конфигурация Phaser.
- [`CHANGELOG.md`](./CHANGELOG.md) — журнал изменений.

Графика прототипа намеренно простая: игрок, мухи, точки зацепа, платформы, вода и шипы нарисованы базовыми фигурами Phaser.
